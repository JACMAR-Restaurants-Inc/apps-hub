# Apps Hub

The portal and internal apps, on Next.js, Supabase Postgres and Vercel (Montréal).

    npm install
    cp .env.example apps/web/.env.local   # fill in staging values
    npm test && npm run typecheck
    npm run dev

Read `CLAUDE.md` before changing anything. `docs/CUTOVER.md` is the approval-day checklist.
